# 전략적 컨텍스트 정리

현재 세션의 컨텍스트를 전략적으로 정리하여 작업 효율을 높인다.

## 판단 기준

### /compact 사용 (컨텍스트 내 정리)
- 같은 영역에서 계속 작업할 때
- 탐색 결과가 많이 쌓였을 때
- $ARGUMENTS가 있으면 해당 영역에 집중하여 압축

### /clear 사용 (완전 초기화)
- 완전히 다른 영역으로 전환할 때
- 에러 루프 3회 이상 반복될 때
- Claude가 규칙을 무시하기 시작할 때

### HANDOFF.md 작성 후 /clear
- 복잡한 진행 중 작업을 다른 세션에 넘길 때
- 먼저 `/handoff`를 실행하여 HANDOFF.md를 작성한 후 `/clear`

## 절차

### /compact 경로
1. 현재 작업 상태 요약
2. `/compact $ARGUMENTS` 실행
3. 압축 후 핵심 컨텍스트 유지 확인

### /clear 경로
1. 현재 작업 상태를 HANDOFF.md에 기록:
   ```markdown
   # Handoff

   ## 현재 작업
   - 무엇을 하고 있었는지
   - 어디까지 완료했는지

   ## 다음 단계
   - 구체적인 다음 액션

   ## 참고
   - 관련 파일 경로
   - 주의사항
   ```
2. `/clear` 실행
3. 새 세션에서 `/catchup`으로 복구

## 팁

- 2번 수정 실패 시 /clear 후 더 나은 프롬프트로 재시작 (Boris 패턴)
- MCP 도구가 사용 안 해도 컨텍스트 8-30% 소모 — 필요 시에만 활성화
- /btw로 사이드 질문 (컨텍스트 오염 방지)
